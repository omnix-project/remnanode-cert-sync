# RemnaNode Cert Sync

Скрипт для копирования TLS-сертификата Certbot в каталог сертификатов RemnaNode.

## Что делает

- Запрашивает только домен, например \`example.com\`.
- Берёт файлы из \`/opt/certbot/certs/live/ДОМЕН/\`.
- Копирует \`fullchain.pem\` и \`privkey.pem\` в \`/opt/remnanode/configs/xray/ssl/\`.
- Разыменовывает символьные ссылки Certbot (\`cp -L\`), поэтому в каталоге назначения остаются обычные файлы.
- Проверяет PEM-сертификат, приватный ключ и соответствие открытых ключей.
- Не копирует файлы повторно, если они не изменились.
- Устанавливает владельца \`root:root\`, права сертификата \`644\`, ключа \`600\`.
- По желанию создаёт cron-задачу на проверку каждые 6 часов.

**Скрипт не меняет конфигурацию Xray и не перезапускает Docker-контейнеры или службы.**

## Установка

На сервере RemnaNode выполните:

\`\`\`bash
curl -fsSL https://raw.githubusercontent.com/omnix-project/remnanode-cert-sync/main/install.sh | sudo bash
\`\`\`

Либо скачайте \`install.sh\` и запустите от root:

\`\`\`bash
bash install.sh
\`\`\`

Установщик поместит основной скрипт в \`/usr/local/sbin/sync-remnanode-certs.sh\` и запустит первичную настройку.

Требуются Bash, OpenSSL, coreutils, util-linux (для \`flock\`) и cron, если выбрано расписание.

## Использование

Первичная настройка или изменение домена/расписания:

\`\`\`bash
sudo /usr/local/sbin/sync-remnanode-certs.sh --configure
\`\`\`

Ручная синхронизация:

\`\`\`bash
sudo /usr/local/sbin/sync-remnanode-certs.sh
\`\`\`

Справка:

\`\`\`bash
sudo /usr/local/sbin/sync-remnanode-certs.sh --help
\`\`\`

Конфигурация хранится в \`/etc/remnanode-cert-sync.conf\` с правами доступа только для root. Лог cron-задачи: \`/var/log/remnanode-cert-sync.log\`.

## Пути

| Назначение | Путь |
|---|---|
| Источник Certbot | \`/opt/certbot/certs/live/ДОМЕН/\` |
| Сертификат | \`fullchain.pem\` |
| Приватный ключ | \`privkey.pem\` |
| Каталог назначения | \`/opt/remnanode/configs/xray/ssl/\` |

## Важно про применение сертификата

Успешное копирование обновляет файлы на диске, но само по себе **не гарантирует**, что уже запущенный Xray немедленно перечитает их. Это зависит от способа подключения файлов и механизма загрузки сертификатов в используемой версии Xray/RemnaNode. Скрипт намеренно ничего не перезапускает. После установки проверьте, что указанные пути действительно смонтированы/доступны процессу, и отдельно определите безопасный способ применения нового сертификата для вашей конфигурации.

## Безопасность

Приватный ключ копируется с правами \`0600\`. Не публикуйте его, не отправляйте в чаты и не меняйте права на более открытые.
